Sistema de clasificación automática de radiografías de tórax basado en una red neuronal convolucional (CNN) entrenada con el dataset Chest X-Ray Images (Pneumonia) de Kaggle.

El modelo clasifica cada imagen en una de las tres categorías siguientes:

Normal Neumonía Bacteriana Neumonía Vírica
